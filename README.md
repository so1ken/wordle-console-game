# Wordle

Консольная игра в духе популярного Wordle. Программа загадывает случайное слово из 5 русских букв, а задача игрока — угадать его за 6 попыток.

## 📖 Правила игры

После каждой попытки игра показывает подсказку для каждой буквы:
*   ✅ — буква стоит на своём месте.
*   🟡 — буква есть в слове, но находится в другой позиции.
*   ❌ — буквы нет в загаданном слове (или все её вхождения уже использованы).

**Главная особенность:** игра корректно обрабатывает повторяющиеся буквы (использует двухпроходный алгоритм) и поддерживает воспроизводимость. Если запустить игру с одинаковым `seed`, загадывается одно и то же слово.

## 🚀 Быстрый старт
Для запуска понадобится **JDK 25** или новее. Gradle устанавливать не нужно, в проекте есть `gradlew`

# Запустить интерактивную игру
./gradlew run

# Запустить режим автопроверки (демонстрация работы логики)
./gradlew run --args="check --answer озеро --guess арбуз"

# Запустить все тесты и линтеры 
./gradlew check
## MR1 — Данные и игровая сессия

### Что реализовано
- `Dictionary` — неизменяемая модель словаря с валидацией (≥50 слов и каждое ровно 5 букв).
- `DictionaryReader` — загрузка слов из classpath (`/dictionary.txt`), пропуск пустых строк и комментариев `#`.
- `GameStatus` — enum со статусами `IN_PROGRESS`, `WIN`, `LOSE`.
- `GameSession` — модель одной партии (answer, maxAttempts, attemptsUsed, attemptsHistory, status).
- `GameService.startGame(dict, maxAttempts, seed)` — детерминированный выбор слова по seed.

- Воспроизводимость: seed задаётся в вызове `startGame`, одинаковый seed → одинаковое слово.

### Принятые решения
- **Структура пакетов:** `model` — данные (словарь), `game` — игровая логика (сессия, сервис).
- **Чтение словаря:** через `getResourceAsStream("/dictionary.txt")` с явной кодировкой UTF-8.
- **Инкапсуляция:** `Dictionary` хранит `List.copyOf(input)` — нельзя изменить содержимое.

## MR2 — Правила игры

### Реализовано
- `LetterStatus` — enum: CORRECT (✅), PRESENT (🟡), ABSENT (❌).
- `GuessResult` — результат одной попытки (список из 5 статусов).
- `GameService.applyGuess(session, guess)` — валидация, проверка победы, двухпроходный алгоритм.
- Валидация: длина 5, только буквы, слово в словаре, ввод без учёта регистра.
- Некорректный ввод не тратит попытку.
- WIN при угадывании, LOSE после 6 неудачных попыток.

### Принятые решения
- **Двухпроходный алгоритм:** сначала отмечаются все ✅ (буква на месте), затем оставшиеся буквы ищутся среди **неиспользованных** букв ответа. Каждое вхождение буквы ответа расходуется один раз.
- **`computeStatuses(answer, guess)`** вынесен в отдельный метод: не знает про сессию, словарь и валидацию.

## MR3 — Интерфейс и проверяемость

### Реализовано
- `ConsoleUI` — вывод в консоль: эмодзи ✅🟡❌, меню, сообщения о победе/поражении.
- `GameRunner` — цикл одной партии: читает ввод, обрабатывает ошибки, рендерит результат.
- `Main` — меню (новая игра / выход), несколько партий подряд.

### Запуск
- Интерактивно: `./gradlew run`
- Режим проверки: `./gradlew run --args="check --answer озеро --guess арбуз"`
- Тесты: `./gradlew check`

### Принятые решения
- **Разделение ответственности:** `ConsoleUI` только печатает, `GameRunner` управляет циклом, `Main` — точка входа.
- **Обработка EOF:** при `NoSuchElementException` (stdin закрыт) программа корректно завершается с кодом 0.
